To safely pause a running pipeline, press CTRL + SHIFT + P. The pipeline will finish its current operation, 
save its state, create a run-specific pause flag, and stop execution gracefully, 
allowing the job to be resumed later using the original Run ID. To immediately stop a pipeline run, press CTRL + SHIFT + Q. 
This triggers an abort request, terminates the pipeline execution, 
marks the run as aborted, and performs cleanup of temporary control files. 
When resuming a paused run, execute the pipeline using the --resume and --run-id arguments to continue 
from the last completed stage instead of restarting the entire workflow.
