Step 1: Stop the Running Process -ok

- Monitor the terminal.

- Once you see ==== FINAL RESULT ==== , press Ctrl + C to safely stop the process. 

Step 2: Close the Browser -ok

- Close the Chrome browser (or any browser used to access WebODM).

Step 3: Properly Stop Docker Desktop

- Click the Windows System Tray (bottom-right corner of the taskbar). -ok

- Right-click the Docker Desktop icon. -ok

- Select “Quit Docker Desktop.” -ok

- Wait until Docker fully shuts down (the icon will disappear).

Step 4: Shut Down the PC

- Once Docker has completely stopped, you may safely shut down the computer.
